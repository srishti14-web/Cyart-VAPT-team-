# Week 4 – Vulnerability Assessment and Reporting

## Overview

This folder contains the activities, report, and supporting evidence completed during Week 4 of the VAPT Internship Program. The objective of this task was to perform a vulnerability assessment on the target environment, analyze identified security issues, and document the findings along with remediation recommendations.

## Contents

* **Week 4 Report.pdf** – Detailed assessment report containing methodology, findings, risk analysis, and recommendations.
* **Screenshots/** – Evidence collected during scanning, testing, and validation activities.

## Tools Used

* Nmap
* OpenVAS / Greenbone
* Burp Suite
* Web Browser Developer Tools

## Activities Performed

* Conducted vulnerability assessment on the target environment.
* Identified exposed services and potential security weaknesses.
* Analyzed scan results and validated findings.
* Documented vulnerabilities and their potential impact.
* Prepared remediation recommendations based on identified risks.

## Results Summary

The assessment successfully identified multiple security observations related to service exposure, configuration weaknesses, and potential vulnerabilities. Findings were documented according to their severity and impact. Appropriate remediation measures were recommended to improve the overall security posture of the target environment.

## Outcome

This task provided practical experience in vulnerability assessment, result analysis, security reporting, and evidence documentation using industry-standard cybersecurity tools and methodologies.
