# Week 1 - Security Assessment Fundamentals

## Objective
Understand Security Assessment concepts, VAPT methodology, security standards, risk assessment, vulnerability identification, and reporting fundamentals.

## Topics Covered
- Security Assessment
- VAPT Methodology
- Security Standards & Compliance
- Risk Assessment Basics
- Common Vulnerabilities
- Documentation Fundamentals

## Practical Activities
- Kali Linux Setup
- VirtualBox Configuration
- OpenVAS Installation
- Vulnerability Scanning
- Risk Assessment
- Report Preparation

## Tools Used
- Kali Linux
- OpenVAS
- Nmap
- VirtualBox
- CVSS Calculator
- Microsoft Excel

## Deliverables
- Security Assessment Report
- Risk Register
- Supporting Screenshots
